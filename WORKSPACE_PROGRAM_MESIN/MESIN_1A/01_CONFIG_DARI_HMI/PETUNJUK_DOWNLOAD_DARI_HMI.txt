================================================================================
PETUNJUK MENGAMBIL FILE KONFIGURASI DARI HMI KONTROLER MESIN CELUP
================================================================================

Folder ini adalah tempat Anda menaruh file konfigurasi yang didownload
dari HMI mesin celup (SETEX / SECOM 777, 737, 838).

1. FILE YANG PERLU DIAMBIL DARI HMI:
   ---------------------------------
   - TYPECONF.CNF  <-- [PENTING] Berisi daftar fungsi (F-Code) dan parameter PLC
   - CONFTEXT.CNF  <-- [PENTING] Berisi kamus teks label parameter bahasa Indonesia/Inggris
   - MACHCONF.CNF  <-- [PENTING] Berisi nomor mesin, kapasitas Kg, dan jumlah tangki
   - FNLEGEND.CNF  <-- [Opsional] Keterangan handshake langkah proses
   - TYPECONT.CNF  <-- [Opsional] Pengaturan batas kontrol & level

2. CARA MENGAMBIL FILE DARI HMI (VIA Storage):
   ----------------------------------------------
   a. Tancapkan USB Storage ke port USB pada layar HMI SETEX di mesin.
   b. Buka Windows Explorer di Windows CE HMI.
   c. Masuk ke folder: \Storage\sc777ce\Config\  (atau C:\sc777ce\Config\)
   d. Salin (Copy) file TYPECONF.CNF, CONFTEXT.CNF, dan MACHCONF.CNF.
   e. Tempel (Paste) ke USB Storage Anda.
   f. Bawa Storage ke komputer server ini, lalu paste ke folder ini:
      WORKSPACE_PROGRAM_MESIN/<NAMA_MESIN>/01_CONFIG_DARI_HMI/

3. CARA MENGAKTIFKANNYA DI OPENORGATEX:
   -------------------------------------
   Setelah file ditaruh di folder ini, jalankan perintah di terminal:
      python WORKSPACE_PROGRAM_MESIN/kelola_mesin.py --sync <NAMA_MESIN>

   Sistem akan otomatis mengurai (decode) file tersebut ke folder
   02_CONFIG_SIAP_PAKAI sehingga OpenOrgaTEX langsung mengenali fungsi resmi
   mesin tersebut saat Anda membuat program celup!
================================================================================
